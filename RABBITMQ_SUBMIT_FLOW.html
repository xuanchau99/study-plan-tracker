Sơ Đồ Giả Lập Luồng Nộp Bài RabbitMQ

Bấm nút chạy giả lập để quan sát đường đi của dữ liệu từ Frontend xuống Database trong kiến trúc bất đồng bộ.

Hệ thống đang chờ đợi...
1

Frontend React (Vite)

frontend/src/api.js
fetchApi()

Học sinh bấm "Nộp bài". Dữ liệu user lấy từ JWT, ID bài thi lấy từ URL.

fetchApi(`/exams/${quizId}/submit`, { method: 'POST' });
2

Main Thread (Spring)

.../controller/ExamController.java
@PostMapping()
public ResponseEntity submitExam(...)

Nhận request, tạo Event. Trả về HTTP 202 ngay lập tức mà không đợi chấm điểm.

examService.submitExam(userId, quizId); return ResponseEntity.accepted().build(); // Trả về 202 ngay tức thì
3

RabbitMQ Broker

.../service/ExamService.java
rabbitTemplate.convertAndSend(...)

Đẩy Event nộp bài vào Message Queue để chờ xử lý ngầm.

ExamSubmittedEvent event = new ExamSubmittedEvent(userId, quizId); rabbitTemplate.convertAndSend( RabbitMQConfig.EXCHANGE_NAME, "exam.submit", event );
7

STOMP WebSocket

frontend/src/App.jsx
client.subscribe()

Nhận JSON thông báo. React dùng toast() để hiện Pop-up góc màn hình.

client.subscribe('/user/queue/notifications', (msg) => { toast.success(JSON.parse(msg.body).message); } );
4

Background Worker

.../service/ExamProcessorService.java
@RabbitListener
public void processExamSubmission()

Worker bắt Event. Làm nhiệm vụ trung tâm: Rút đáp án, chấm điểm, lưu DB, báo cáo.

@RabbitListener(queues = RabbitMQConfig.QUEUE_NAME) public void processExamSubmission(Event e) { // 1. Kéo đáp án từ Redis // 2. Tính điểm // 3. Lưu xuống PostgreSQL // 4. Bắn WebSockets }
5

Redis Cache

.../service/ExamProcessorService.java
redisTemplate.opsForHash().entries()

Cung cấp toàn bộ đáp án của user cho Worker với độ trễ siêu thấp O(1).

String key = "exam:" + quizId + ":user:" + userId; Map userAnswers = redisTemplate.opsForHash().entries(key);
6

PostgreSQL

.../repository/ExamResultRepository.java
examResultRepository.save(...)

Lưu vĩnh viễn bảng điểm và bằng chứng vào Database.

ExamResult result = new ExamResult( userId, quizId, score, evidence ); examResultRepository.save(result);
