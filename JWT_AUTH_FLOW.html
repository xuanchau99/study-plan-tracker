Sơ Đồ Giả Lập Authentication (JWT)

Mô phỏng cơ chế xác thực Stateless. Máy chủ không cần lưu Session, chỉ cần sinh ra Chữ ký điện tử (Token) ở khâu đăng nhập, và JwtAuthenticationFilter sẽ tự động gác cổng kiểm tra tính hợp lệ ở mọi request tiếp theo.

Hệ thống sẵn sàng...
1

Trình duyệt (Client)

frontend/src/auth.js
localStorage.setItem('token', jwt)

Nơi gửi request Đăng nhập và sau đó kẹp Token vào Header cho các request sau.

// Header tự động đính kèm Authorization: Bearer eyJhbGci...
2

API Đăng Nhập

AuthController -> AuthenticationManager -> UserRepository -> DB
generateToken(username)

Controller gọi Service truy vấn DB kiểm tra User/Pass. Trùng khớp thì xuất chuỗi JWT bằng Secret Key và trả về.

String jwt = Jwts.builder() .setSubject(user.getUsername()) .signWith(key) .compact(); return jwt;
3

Bộ lọc Bảo Mật (Filter)

.../security/JwtAuthenticationFilter.java
doFilterInternal(...)

Luôn chạy trước Controller. Bắt Header, bóc mã Token và giải mã. Nếu bị làm giả, từ chối truy cập ngay lập tức.

if (jwtUtil.validateToken(token)) { SecurityContextHolder.getContext() .setAuthentication(auth); } filterChain.doFilter(req, res);
4

API Nội Bộ (Protected)

QuizController.java -> QuizService.java -> QuizRepository.java -> DB
@GetMapping("/quizzes")

Chỉ được gọi khi Filter cấp quyền qua. Mọi lệnh truy xuất đến Repository lúc này là an toàn tuyệt đối.

// Controller hoàn toàn tin tưởng Filter return quizRepository.findAll();
