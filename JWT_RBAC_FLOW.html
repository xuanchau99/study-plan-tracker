Cơ Chế Phân Quyền & Điều Hướng (RBAC)

Giải thích cách hệ thống phân biệt Admin và Học sinh thông qua Chữ ký Token, và cách ứng dụng thực hiện điều hướng (Routing) ở cả phía giao diện (Frontend) lẫn bảo vệ API (Backend).

Hệ thống sẵn sàng...
1

Gắn Quyền vào Token

.../security/JwtUtil.java
generateToken(UserDetails user)

Khi đăng nhập thành công, Backend lấy Role (ví dụ ROLE_ADMIN) từ DB và "đóng dấu" vào phần Payload của Token.

Map<String, Object> claims = new HashMap<>(); // Nhét Role vào Token claims.put("roles", user.getAuthorities()); return createToken(claims, user.getUsername());
2

Frontend Điều Hướng

frontend/src/App.jsx (React Router)
Navigate()

React giải mã Token ở phía Client. Nhìn thấy chữ ROLE_ADMIN liền tự động chuyển hướng màn hình sang trang Dashboard.

const payload = jwt_decode(token); if (payload.roles.includes('ROLE_ADMIN')) { navigate('/admin-dashboard'); } else { navigate('/student-home'); }
3

JwtFilter (Backend)

.../security/JwtAuthenticationFilter.java
doFilterInternal(...)

Khi Admin gọi API bóc Token ra, Filter đọc được ROLE_ADMIN và nạp vào Ngữ cảnh bảo mật (SecurityContext) của Spring.

List<GrantedAuthority> roles = extractRoles(token); UsernamePasswordAuthenticationToken auth = new UsernamePasswordAuthenticationToken(user, null, roles); SecurityContextHolder.getContext().setAuthentication(auth);
4

Bảo Vệ API

.../controller/AdminController.java
@PreAuthorize("hasRole('ADMIN')")

Annotation này chặn mọi request. Nó kiểm tra SecurityContext, nếu có ROLE_ADMIN thì cho gọi hàm, không thì trả về 403 Forbidden.

@PreAuthorize("hasRole('ADMIN')") @GetMapping("/admin/users") public ResponseEntity getAllUsers() { return ResponseEntity.ok(userService.findAll()); }
