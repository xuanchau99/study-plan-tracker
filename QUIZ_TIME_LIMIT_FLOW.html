Sơ Đồ Tính Năng Mở Thi Đồng Thời

Giải thích cơ chế phân quyền Admin cài đặt thời gian bắt đầu/kết thúc bài thi và cơ chế Frontend tự động khóa Box, submit ngầm khi hết giờ đối với User.

Đang chờ sự kiện...
1

Giao Diện Admin

AdminDashboard.jsx -> QuizController.java -> QuizService.java -> QuizRepository.java -> PostgreSQL
Tạo Quiz & Lưu cấu hình thời gian

1. Client: AdminDashboard.jsx gửi payload qua API POST /api/v1/quizzes.
2. Service: QuizController chuyển cho QuizService.java map dữ liệu vào Entity.
3. Repository: QuizRepository.java (kế thừa JpaRepository) gọi hàm save().
4. Database: Hibernate tự động sinh câu lệnh INSERT INTO quizzes (is_active, start_time, end_time) để lưu xuống PostgreSQL.

{ "status": "ACTIVE", "startTime": "2026-09-12 08:00:00", "endTime": "2026-09-12 09:30:00" }
2

Giao Diện User

UserDashboard.jsx -> TakeQuiz.jsx
Kiểm tra điều kiện & Chạy setInterval()

UserDashboard.jsx dùng hàm .filter(q => q.isActive) để loại bỏ bài ẩn, khóa nút Start nếu now < startTime.
TakeQuiz.jsx sử dụng setInterval để đếm lùi thời gian dựa trên endTime của bài thi.

3

Hết Giờ (Time's Up)

TakeQuiz.jsx -> ExamService.java -> RabbitMQ -> ExamProcessorService -> ExamResultRepository -> DB
Auto Submit & validateQuizTime()

1. Client: Khi time = 0, TakeQuiz.jsx khóa UI (isLocked = true) và gọi API Submit ngầm.
2. Validate: ExamService.java dùng validateQuizTime() chặn mọi truy cập quá giờ (ngừa tool cheat).
3. Queue: Nếu hợp lệ, Service đẩy payload vào RabbitMQ.
4. Repository & DB: ExamProcessorService lấy đáp án từ Redis chấm điểm, gọi ExamResultRepository.save() để Hibernate INSERT INTO exam_results lưu vào PostgreSQL.
