Sơ Đồ Giả Lập O(1) Auto-Save Bằng Redis

Mô phỏng tốc độ phản hồi cực nhanh khi học sinh click chọn đáp án. Database (PostgreSQL) hoàn toàn bị cô lập để bảo vệ tải.

Hệ thống đang chờ đợi sự kiện Click chọn đáp án...
1

Học sinh chọn đáp án

frontend/src/pages/TakeQuiz.jsx
fetchApi()

Mỗi khi user thay đổi đáp án, Frontend bắn ngầm request lưu tự động.

fetchApi(`/exams/${quizId}/...`, { method: 'POST', body: JSON.stringify({ answer: "C" }) });
2

ExamController (Spring)

.../controller/ExamController.java
@PostMapping(...)
public ResponseEntity autoSave(...)

Nhận kết quả và gọi Service. Tuyệt đối không gọi tới JPA Repository.

examService.autoSaveAnswer( userId, quizId, qId, req.getAnswer() ); return ResponseEntity.ok().build();
3

Redis Hash (RAM)

.../service/ExamService.java
redisTemplate.opsForHash().put(...)

Ghi đè đáp án thẳng vào RAM (O(1)). Bất chấp hàng triệu request.

String key = "exam:" + quizId + ...; redisTemplate.opsForHash().put( key, String.valueOf(qId), answer );
